# Ant Colony and Pheromone Simulation

> A Simulation of an ant colony, showcasing emergent behavior through modeling how ants locate food and establish routes using trails of pheromones, eventually converging on the most efficient path.

---

## Features

- **Graphics:** Graphic rendering of the simulation using the Processing programming language within Java.
- **Procedurally Generated Music:** As ants deposit pheromones, music is generated procedurally in accordance to their movement.
- **Agent-Based Simulation:** Each ant is it's own individual with it's own behavior. The colony communicates solely through pheromones left behind by other ants.
- **Convergent Behavior:** Overtime, the ants converge on an efficient path between their nest and food source, as the intensity of pheromones is increased by more ants using the trail.
